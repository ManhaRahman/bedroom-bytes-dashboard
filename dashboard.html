Notes

The <kbd> tag formats text in the way they are in your keyboard.

The <meter> tag allows you to create a bar representing a value written in decimal.

The <canvas> tag allows you to create a blank canvas which can be used for drawing and coordinating with JS

The <small> tag allows you to make text which is smaller than regular paragraph text.

The <del> and <ins> tag always come together. It's like cutting out a mispelled or wrong word in your English notebook! Only, with the newly inserted text being underlined.

The <s> tag stands for 'Strikethrough' and puts a line over the center of the text you write inside it.

The <datalist> tag has an id, which is the name of the list you use in the input tag, and inside it, you keep some predefined options, whose values are written inside a value attribute. This option tag is self-ending.

The <details> tag has a <summary> tag which acts as a heading, and then, in a paragraph you write some text which can be seen or hidden, depending on whether the heading is clicked or not.

Notes

A <div> element creates an invisible box, which is useful for sectioning different items, just like in your dashboard!

To make it visible, you can use 'background-color', 'color' and 'border'. Additionally, you can set some space inside the borders using 'padding', and align text to the center using 'text-align'.

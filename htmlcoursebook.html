Chapter 1: Introduction

Welcome to the Syntax Bytes HTML Coursebook! HTML stands for HyperText Markup Language. It is the absolute foundation of everything you see on the World Wide Web.

Think of a website like building a house. HTML isn't the paint or the furniture—it's the structural skeleton. It places the walls, the doors, and the window frames where they belong. In fact, this coursebook's foundation was made with HTML too!

Let's look at the anatomy of an HTML document:

  1. <!DOCTYPE html> → It's a declaration that's basically saying 'This is a HTML document'.

  2. <html> </html> → This is the root element from within which, all the entire page structure branches out. It's best practices to add the lang attribute to set the language in which the words should be written in.

  3. <head> </head> → This part of our HTML stores invisible metadata like configurations and page titles.

  4. <title> </title> → It is written in the head tag and sets the title of the web page visible on the tab.

  5. <body> </body> → Contains the visible content which the user interacts with.

Quick Fact: Have you ever seen elements inside another? They're called nested elements.

HTML<!DOCTYPE html>
<html lang="en">
  <head>
    <title>My First Page</title>
  </head>
<body>
    <h1>Hello World!</h1>
  </body>
</html>

Chapter 2: Elements & Tags

HTML uses tags to build components. Tags are words or letters trapped inside angle brackets like this: <tagname>. Most tags are in pairs and have closing tags, such as <h1> </h1>, but some of them don't have ending tags, so they are called self-ending tags. Self ending tags are ones such as <hr> and <br>

Most elements have an opening tag, the content, and a closing tag (which features a forward slash /).

Some basic elements (with, if they have, their ending tags):

  • <h1> </h1> → The main and largest heading, often used at the very beginning of a page.

  • <p> </p> → Used for creating a paragraph.

  • <pre> </pre> → Unlike the paragraph tag, which wraps text and deletes extra spacing by default, this tag presents text exactly how it was written in the source code. So, if you give ten spaces in a <pre> tag, all ten spaces will come, and if you type a very long sentnece, it'll extend all the way beyond the screen, and you'll hae to scroll horizontally to read it!

  • <br> → A self-ending tag used for creating a line break.

  • <hr> → Another useful self-ending tag, which stands for horizontal rule, and makes a visible line break by creating a horizontal line. It can show a change of topic in a website. By default, it shows a thin, grey line, but you can change its thickness and color, or other properties using CSS.


Quick Fact: There are 6 headings, <h1>, <h2>, <h3>, <h4>, <h5> and <h6>, with their respective ending tags.

HTML<h2>This is a heading</h2>
<p>This is a paragraph</p>

Chapter 4: Hyperlinks & Images

Websites wouldn't be very fun if you couldn't move between them or see pictures! We use the anchor tag <a> for hyperlinks and <a> for graphics.

Notice that images do not have a closing tag. They are self-closing and hold elements called attributes like src, for specifying the source (which can come as an image address or a downloaded image path) and alt (alternate text description), in case the image cannot load. The a tag has the href attribute for specifying the link address and between the starting and closing tag, you can write the text that'll lead to the link.

Quick Fact: If an image cannot upload to the web page, the alt attribute helps the user understand what the image was supposed to be about.

Chapter 5: Organizing Information

Imagine looking at a messy bedroom floor covered in clothes, toys, and books. To clean it up, you need different types of containers—like a laundry basket for clothes and a shelf for books.

Websites work the exact same way! When you have a lot of words or data, you can't just throw them onto the page. HTML gives us two powerful structural containers to organize information cleanly: Lists for simple grouped items, and Tables for structured grid data.

Bringing Order with Lists

Lists help us group related items together. HTML gives us three distinct choices depending on whether the sequence matters:

  • Unordered Lists: <ul> </ul>→ Creates a simple bullet pointed sequence when order doesn't matter (like a grocery shopping list).

  • Ordered Lists: <ol> </ol> → Creates a numbered sequence when order is vital (like step-by-step game levels or recipes).

  • Description List: <dl> </dl> → Nest the paired tags <dt> (Description Term, or, historically known as Definition Term) and <dd> (Description Details, or, historically known as Definition Description) inside of the <dl> (Description List) tag, if you want to define a definition directly on a new line with some left margin indent.

Quick Fact: No matter which list type you pick, every single item inside, each, must be wrapped in a <li> (List Item) tag.

HTML <p><strong>Shopping List (Unordered)</strong></p>
  <ul>
    <li>Chocolate Cookies</li>
    <li>Apple Juice</li>
  </ul>

<p><strong>Instructions (Ordered)</strong></p>
  <ol>
    <li>Open the box</li>
    <li>Eat the cookie</li>
  </ol>

Managing Grid Layouts with Tables

Tables allow us to display grid data efficiently using horizontal rows and vertical column alignments. Instead of standard text lines, tables are built using specific layout blocks:

  • <table> → The main wrapper container for the grid data area.

  • <tr> → Defines and stands for Table Row. You can have as many rows as you like in a table, only, make sure that the number of cells in each row are the same.

  • <th> → Do you want to create a table header in a row instead of an ordinary cell? Replace the <td> tag with this tag to create a bolded Table Header for a cell column title.

  • <td> → It defines each cell in a table and stands for Table Data. A table cell can contain all sorts of HTML elements: text, images, lists, links, etc.


Quick Fact: To make your table look elegant and formal, you must use CSS, as a default table doesn't have borders, paddings or margins. Also, modern-day browser versions automatically delete the margin, so that you can remake it completely from scratch. Therefore, if your text inside the <dd> tag isn't coming with some indent, use style="margin-left: 40px" inside your <dd> tag. This is a useful CSS code for adding margin. 40px means the same amount of margining as 4 tabs.

HTML<table>
  <tr>
    <th>Name</th>
    <th>Age</th>
  </tr>
  <tr>
    <td>Manha</td>
    <td>11</td>
  </tr>
</table>

Chapter 6: User Interaction

Forms turn static web documents into interactive experiences. They let your website collect input from users using text boxes, buttons, selections, and checkboxes.

The input from the user then arrives at the erver, where it is used for purposeful actions, such as setting a profile. The inputs can also be changed from time-to-time, which is why you can change your profile picture on sites like GitHub, or reset your username over and over.

Let's take a look at how a simple HTML form can be set, with pair and self-closing tags:

  • <form> </form> → The wrapper that collects all input variables. The rest of the tags are all written inside it, and will stay within it unless they exit the space between the two tags.

  • (Optional) <fieldset> </fieldset> → Used for creating a box with a thin border around your form. It groups related data into one place, so that they don't look stranded like people roaming around deserts.

  • (Optional, if you use a fieldset) <legend> </legend> → It acts as a caption for the fieldset.

  • <input> → A self-closing tag that changes behaviour and shape depending on its type="..." attribute (like text, email, password, or checkbox).

  • <label> </label> → It defines a label for the input, select and textarea tags.

  • <textarea> </textarea> → Often used in forms for comments, and is followed by the row="..." col="..." attributes. They specify how many rows and column sized should the textbox be.

  • <input type="submit" value="Submit"> or <button type="submit">Submit</button> → Acts as an un-interactivez, plain submit button. For making it interactive, such as showing results or a popup, as you see in Sign Up pages, you need to use JS.

Quick Fact: The value attribute has many different meanings! In submitting inputs through a button, it sets the tet displayed on the face of the button. In selections, it sets the data submitted to a server when the user clicks an option. For example, the user may click and see an option titled as Volvo, but when they submit it, the server will recieve volvo-v869. And in ordered lists, they allow us to skip the order of the item, for example, turning the 2nd item into the 10th item while staying in the same position!

HTML<form>
  <input type="text" placeholder="Type your name here...">
  <button type="submit">Submit</button>
</form>

Chapter 7: The Invisible Boxes

When assembling professional interfaces, you need invisible structural blocks to group distinct component sections together neatly. This layout grouping is exactly what the <div> tag handles.

Div stands for "division." It creates an invisible box on the page. It doesn't change how the text looks by default, but it lets you group elements together so you can style them later with CSS or arrange them on the screen.


Block vs. Inline: The Two Types of Boxes


  • (Block Element) <div> </div> → Takes up the full width of the screen. It always starts on a brand new line, forcing everything else below it.

  • (Inline Element) <span> </span> → A tiny container used for small bits of text inside a paragraph. It does not start on a new line, and is used for marking a piece of text or a part of a document


Quick Fact: Don't be too sad if your boxes aren't popping up. Its because they are invisible by default, and to make them pop up, you need to use CSS!

HTML<div style="border: 3px #6c5ce7 double; text-align: center; padding: 10px;">
  <span style="background-color: antiquewhite; color:#4b4b85f7; font-family: 'Comic Sans MS', cursive; padding: 5px;"]>
    Greetings!
  </span>
</div>

Part 1: Scientific & Math Formatting


Sometimes you need to format text for math equations, chemical formulas, or highlight a critical rule snippet on the screen:

  • <mark> </mark> → Highlights text in bright neon yellow.

  • <sub> </sub> → Stands for Subscript and lowers characters slightly below the text baseline (like the 2 in H2O).

  • <sup> </sup> → Stands for Superscript and raises characters slightly above the text baseline (like exponents in E=mc2).

Quick Fact: You cna change the highlight color of the <mark> tag using the CSS background-color: ; property. Write the name of your color before the semicolon!

Part 4: Interactive Dropdowns & Collapsible Sections

These built-in HTML structures allow you to hide and reveal information dynamically without needing complex JavaScript configurations:

  • <details> </details> & <summary> </summary> → Creates a clickable drop-down disclosure box. The <summary> tag acts as the clickable title heading.

  • <datalist> </datalist> → Joins forces with a standard text field element to offer a responsive and smart autocomplete suggestions dropdown menu list as the user types.


Quick Fact: UI stands for User Interface. It occurs when humans interact with a device, app or website. Some key components include input controls (buttons, text fields, checkboxes or drop-down menus), navigational elements (scrolling or searching bars), visual styling (icons, color palettes and spacing) and informational components (progress bars).

Part 5: Smart Tools & UI Layouts

These tags introduce rich interface modules like pop-up windows, keyboard keys, asset gauges, and graphics canvases directly to the document architecture:

  • <kbd>: Formats text to look like physical computer keyboard button keys.

  • <meter>: Renders a visual status bar representing values inside an <option> tag. The values are set inside this tag using the value="..." attribute, and are always in decimal format.

  • <dialog> </dialog> → Creates a box-window container around the text.

  • <canvas> </canvas> → An empty container area designed for creating graphics, game animations, or sketches using JavaScript coordinates.


Quick Fact: Attributes are always put inside tags, and are followed immediatel by an ="...". Inside the quotes you write the values.
